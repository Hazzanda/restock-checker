# restock-checker
A project to check whether a product should be restocked.

## Why I built it
From my experience in FMCG, I realised a key determinant of success is avoiding Out-Of-Stock situations.
I am learning from University of Helsinki's Python MOOC (mooc.fi)

## What I learned
- User input
- Type conversion
- if / elif / else logic in an edge case

## How to run
python restock_checker.py
